# Database SQL Basics

## Overview
A database is a structured system used to store, organize, and retrieve data efficiently. 
SQL (Structured Query Language) is the standard programming language used to communicate with relational databases, allowing applications to request specific information, update records, or delete data.

## Security Relevance
Databases are prime targets in cybersecurity because they house an organization's most valuable and sensitive information, including user credentials and financial records.

## New Terms / Key Concepts
**SQL Queries I Learned**
- SELECT – choose what data to display
- FROM – choose where the data comes from
- WHERE – filter records based on a condition
- ORDER BY – sort results
