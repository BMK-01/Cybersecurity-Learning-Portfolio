# CIA Triad

## Overview
The CIA Triad is a foundational information security model consisting of three core principles: Confidentiality, Integrity, and Availability. 
It serves as a guiding framework for organizations to evaluate and implement security controls, ensuring that data is protected from unauthorized access, remains accurate and unaltered, and is reliably accessible to authorized users when needed.

## Security Relevance
The CIA Triad is the core of cybersecurity, answering exactly what is being protected and why. 
By applying this model, defenders can evaluate vulnerabilities and anticipate the goals of threat actors targeting an organization. 
It dictates the implementation of fundamental security mechanisms, such as requiring encryption for confidentiality and hashing for integrity to properly defend systems you already understand.

## What I Learned (Learning Objectives)
* **Confidentiality:** Learned that data must be protected from unauthorized disclosure, ensuring only individuals with the correct permissions can view or access sensitive information.
* **Integrity:** Understood the importance of maintaining the accuracy, consistency, and completeness of data over its lifecycle to prevent unauthorized or accidental modifications.
* **Availability:** Discovered that systems and data must be consistently accessible to authorized users, requiring resilient infrastructure, proper network maintenance, and redundancy.
* **Practical Application:** Explored real-world examples of how to enforce the triad, such as using strong passwords and access controls (Confidentiality), file hashing and digital signatures (Integrity), and backups or load balancers (Availability).
