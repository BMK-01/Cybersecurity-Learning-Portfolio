# Internet Basics (Client-Server basics)

## Overview
The client–server model is a network architecture where a client requests services or resources, 
and a server processes the request and provides a response. For example, a web browser (client) requests a webpage from a web server.

## Security Relevance
The client–server model is important in cybersecurity because communication between clients and servers can be targeted by attackers. 
Security focuses on protecting data, authentication, communication, and server resources from threats such as unauthorized access, 
interception, spoofing, and denial-of-service attacks.
